## 學習地圖與前處理八大重點技能

1. **認識 Excel 介面與導航**：功能區（Ribbon）、名稱方塊快速定位、編輯列、狀態列即時統計與快捷鍵。
2. **整齊資料（Tidy Data）原則**：一列一觀測值、一欄一屬性，嚴禁合併儲存格，0 kg 與空白的正確識別。
3. **欄位拆分**：使用【資料剖析】（Text to Columns）將複合欄位（如「船名航次」）依指定分隔符號拆開。
4. **文字清洗與標準化**：利用 `TRIM`、`CLEAN`、`SUBSTITUTE`、`UPPER` 去除隱形空格、全形空格並統一英文大小寫。
5. **日期序列轉換與防呆**：利用 `DATE`、`TEXT`、`LEFT`、`MID`、`RIGHT` 排除不存在的日曆日期（如 `2026/02/30`）。
6. **數值與單位剝離**：去除千分位逗號與文字標籤，轉為真實可計算數值。
7. **重複鍵識別與移除**：利用 `COUNTIF` 計算出現次數，建立「選擇性貼上值」快照後執行【移除重複項】。
8. **對帳與驗證**：利用 `COUNTA`、`COUNTIF`、`SUMIF`、`SUBTOTAL` 進行總量與交付平衡式核算。

## 快速預覽互動式簡報

直接使用瀏覽器開啟 `航運行政 Excel 資料前處理 互動簡報.html` 或 `index.html` 即可展開教學演講，支援以下鍵盤操作：
- `→` / `Space` / `PageDown`：下一頁
- `←` / `PageUp`：上一頁
- `Home`：返回首頁
- 點擊任一圖片可開啟高解析度放大檢視（按 `Esc` 關閉）
- 點擊單據編號可切換檢驗清洗前後欄位轉換
